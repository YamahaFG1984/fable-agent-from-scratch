快速开始：让代码真正跑起来

读完原理不等于学会了 Agent——本书反复强调"保持 notebook 开着，边读边跑"才是真正的学习方式。这一页把仓库 README.md 和 .env.example 里的步骤，翻译成一份对初学者友好的清单。

需要具备的基础

本书对读者的要求很克制：会用 LLM API 不是必需的，但需要具备 Python 基础——变量/列表/字典等数据结构、if/for 控制流、函数定义、基础的类（OOP）写法；不需要机器学习或 NLP 背景。唯一真正的前提是：愿意亲手跑代码、改代码。

四步上手

终端 / shell
# 1. 克隆仓库，安装 uv（Python 包管理器，还没装过的话）
git clone <你的仓库地址>
cd ai-agent-from-scratch
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. 安装全部依赖 —— 读取 uv.lock，版本和作者跑通的完全一致
uv sync

# 3. 配置 API Key
cp .env.example .env
# 用编辑器打开 .env，按下表填入需要的几项

# 4. 启动 Jupyter Lab，跟着每章的 notebook 一起跑
uv run jupyter lab

需要哪些 API Key

变量用途必需程度花费
OPENAI_API_KEY全书默认模型，几乎每章都要用必需全书跑完 < $10

读指南 ≠ 学会了

这份指南负责把原理和架构"画"给你看，但本书真正的学习曲线在 notebook 里——改一个参数、故意搞坏一个工具、换一个模型，看 Agent 的行为怎么变。每一章末尾新增的"动手试一试"就是为了把这一步接回来。
